# poltava-alerts

Історія повітряних тривог Полтавського району (Полтавська область) за
останній місяць — для статистики «скільки робочого часу під тривогою» в
застосунку класного керівника.

**Дані: [alerts.in.ua](https://alerts.in.ua)** — публічне API
(https://devs.alerts.in.ua), записи з офіційних джерел. Сервіс інформаційний,
не канал оповіщення.

Файл `data/poltavskyi.json` щодня о 05:30 (Київ, літній час) перезаписує
GitHub Action: один запит `month_ago.json` по області, з нього — тривоги
району й області. Нічого не накопичується: у файлі завжди рівно місяць,
`from` → `through` (`through` — момент, коли сервер зібрав відповідь).
`end: null` — тривога ще тривала.
